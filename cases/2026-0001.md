### What was found

26 of the 27 items bundle a loader named `PWLoader.dll` (7168 bytes, two versions) and list it in the manifest as an assembly to load. When the mod initializes, the loader:

1. starts a background thread;
2. downloads an exe from an external server and saves it as `%LOCALAPPDATA%\SteamAlertDemo\Application Frame Host.exe`, a name imitating the Windows system process `ApplicationFrameHost.exe`;
3. runs that exe, using the process name to avoid starting it twice.

It calls the Windows functions `URLDownloadToFileW` and `ShellExecuteW` directly, so it gets past the game's block on `Process.Start`.

The downloaded program was not retrieved for analysis, so **what it does is unknown**. The code calls it `resident`. An older version of the loader also syncs a file named `like_target.txt`, which by its name may be related to boosting ratings; that is only a guess.

Older loaders left inside the items (`PSCompat*.dll.bak_*`) use `WebClient` and `Process.Start`. The game's scanner refuses this: as a listed assembly it counts as `process-start`, as a leftover file as `payload-file`. Mod Guard's import rules cannot see it, since it imports no Windows functions: **this kind of code has to be stopped by the game itself**. The backup files show that the author then switched to the current technique.

### How to reproduce

Open `PWLoader.dll` from any of the items in ILSpy and look at `StartWorker`, called by `PWLoaderMod.Init`: the download address, the save path and the call that starts the program are all there. Do not run it.

### 发现了什么

27 个条目里有 26 个夹带名为 `PWLoader.dll` 的加载器（7168 字节，两个版本），并在 manifest 里列为要加载的程序集。它在模组初始化时：

1. 开一个后台线程。
2. 从外部服务器下载一个 exe，存到 `%LOCALAPPDATA%\SteamAlertDemo\Application Frame Host.exe`。这个名字模仿 Windows 系统进程 `ApplicationFrameHost.exe`。
3. 运行这个 exe，并用进程名避免重复运行。

它直接调用 Windows 函数 `URLDownloadToFileW` 和 `ShellExecuteW`，所以不经过游戏对 `Process.Start` 的拦截。

下载到的程序没有取回分析，**它具体做什么未知**。代码里把它称作 `resident`（常驻程序），旧版加载器还会同步一个名为 `like_target.txt` 的文件，从名字看可能与刷好评有关，这只是推测。

条目里残留的旧版加载器（`PSCompat*.dll.bak_*`）用的是 `WebClient` 和 `Process.Start`。游戏扫描器会拒绝这种写法：作为列出的程序集时算 `process-start`，作为残留文件时算 `payload-file`。守卫的导入规则看不到它，因为它没有导入 Windows 函数，**这类写法要靠游戏自己挡**。从备份文件看，作者随后把它换成了现在的写法。
